Examples

Examples

Examples

Speaking Practice
🗣️
หัวข้อที่ 1: คุยเรื่องโปรเจกต์กับภรรยา
hǔua-kɔ̂ɔ tîi nùeng: kui rʉ̂ʉang bproh-jèk gàp pan-rá-yaa
Task 1: Talking about a project with your wife
🏗️
ลองแต่งประโยคจากคำที่เค้กให้นะคะ: โปรเจกต์โรงหนัง / ดีกว่าที่คิด
lɔɔng dtàeng bprà-yòk jàak kam tîi kéek hâi ná ká: bproh-jèk rohng-nǎng / dii-gwàa tîi kít
Try to make a sentence from these words: The cinema project / better than I thought.
Examples
โปรเจกต์โรงหนังดีกว่าที่คิด
bproh-jèk rohng-nǎng dii-gwàa tîi kít
The cinema project is better than I thought.
🔊
ลองแต่งประโยคนี้ค่ะ: ระบบเสียงดี / จอดี / ด้วย / ก็
lɔɔng dtàeng bprà-yòk níi kâ: rá-bòp sǐang dii / jɔɔ dii / dûai / gɔ̂
Try to make this sentence: The sound system is good / the screen is good / too.
Examples
ระบบเสียงดี จอก็ดีด้วย
rá-bòp sǐang dii, jɔɔ gɔ̂ dii dûai
The sound system is good, and the screen is good too.
💬
ทีนี้ลองคุยกับลูก (เค้ก) นะคะ สมมติว่าเพิ่งทำงานเสร็จ โปรเจกต์ใหม่เป็นยังไงบ้างคะ
tii-níi lɔɔng kui gàp lûuk (kéek) ná ká. sǒm-mút wâa pôeng tam-ngaan sèt. bproh-jèk mài bpen yang-ngai bâang ká
Now, try talking to your wife (Cake). Imagine you just finished work. How is the new project?
Examples
คุณ: โปรเจกต์ใหม่ดีกว่าที่คิด
เค้ก: จริงเหรอคะ ดีจังเลย แล้วลูกค้าชอบไหมคะ
คุณ: ลูกค้าชอบมาก ระบบเสียงดี จอก็ดีด้วย
kun: bproh-jèk mài dii-gwàa tîi kít
kéek: jing rə̌ə ká, dii jang ləəi. láaeo lûuk-káa chɔ̂ɔp mái ká
kun: lûuk-káa chɔ̂ɔp mâak. rá-bòp sǐang dii jɔɔ gɔ̂ dii dûai
You: The new project is better than I thought.
Cake: Really? That's great! Does the client like it?
You: The client likes it a lot. The sound system is good, and the screen is good too.
🗓️

สมมติว่าคุณคุยกับลูกชาย/ลูกสาว (เค้ก) ค่ะ ลองชวนเขาดูหนังคืนนี้สิคะ
