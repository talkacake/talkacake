โยธา: อันนี้ แฟนเลือกให้ครับ
yoh-taa: an-níi faen lʉ̂ak hâi kráp
Yotha: This one, my girlfriend/boyfriend chose for me.
Examples
อันนี้ (an-níi) = This one / This thing
แฟน (faen) = boyfriend / girlfriend / partner
เลือกให้ (lʉ̂ak hâi) = to choose for (someone)
ตัวอย่าง (dtua-yàang) Structure:
1. เพื่อนเลือกเสื้อผ้าให้
2. แม่เลือกหนังสือให้
3. เค้กเลือกเพลงนี้ให้
ลองแต่งประโยคของตัวเองดูนะคะ (lawng sâang bprà-yòk kŏng dtua-eeng doo ná ká)
pʉ̂an lʉ̂ak sêuua-phâa hâi
mâe lʉ̂ak năng-sĕu hâi
kêk lʉ̂ak pleeng níi hâi
A friend chose the clothes for me.
Mom chose the book for me.
Cake chose this song for you.
Try to create your own sentence.

โยธา: อันนี้ ของแฟนครับ
yoh-taa: an-níi kŏng faen kráp
Yotha: This is my girlfriend's/boyfriend's.
Examples
อันนี้ของ... (an-níi kŏng...) = This belongs to... / This is...'s
โครงสร้าง (kroong-sâang) Structure: อันนี้ + ของ + คน
ตัวอย่าง (dtua-yàang) Example:
1. อันนี้ของเพื่อน
2. อันนี้ของแม่
3. อันนี้ของนักร้องคนนั้น

This is my friend's.

This belongs to that singer.
Try to create your own sentence.

มาฝึกพูดกันค่ะ

Let's Practice Speaking
✍️
กิจกรรมที่ 1: นี่ของใคร? ลองเติมคำในช่องว่างค่ะ
gìt-jà-gam tîi nʉ̀ng: nîi kŏng krai? lawng dterm kam nai chông wâang kâ
Activity 1: Whose is this? Let's fill in the blanks.
Examples
1. อันนี้ของ ___________ (friend)
2. โทรศัพท์เครื่องนี้ของ ___________ (mom)
3. หนังสือเล่มนี้ของ ___________ (student)
4. เสื้อสีชมพูตัวนี้ของ ___________ (younger sister)
5. คอมพิวเตอร์ของ ___________ (older brother)
Instructions: Read the sentences and have the student fill in the blank with a person (e.g., friend, mom, dad, a singer's name). Provide the Thai words for family members if needed.
1. This is ___'s. (friend)
2. This phone is ___'s. (mom)
3. This book is ___'s. (student)
4. This pink shirt is ___'s. (younger sister)
5. The computer is ___'s. (older brother)
🔄
กิจกรรมที่ 2: เรียงประโยคให้ถูกต้องค่ะ
gìt-jà-gam tîi sŏng: riang bprà-yòk hâi tòok-dtông kâ
Activity 2: Put the sentences in the correct order.
Examples
1. เพื่อน / ของ / อันนี้
2. ของ / แม่ / มือถือ
3. เลือกให้ / อันนี้ / แฟน
4. ของ / เสื้อผ้า / ฉัน
pʉ̂an / kŏng / an-níi
kŏng / mâe / muue-tĕu
lʉ̂ak hâi / an-níi / faen
kŏng / sêuua-phâa / chăn
Instructions: Ask the student to unscramble these words to make correct sentences.
1. friend / of / this one --> อันนี้ของเพื่อน (an-níi kŏng pʉ̂an)
2. of / mom / phone --> มือถือของแม่ (muue-tĕu kŏng mâe)
3. chose for me / this one / partner --> อันนี้แฟนเลือกให้ (an-níi faen lʉ̂ak hâi)
4. of / clothes / I --> เสื้อผ้าของฉัน (sêuua-phâa kŏng chăn)
🙋‍♀️
กิจกรรมที่ 3: ของในห้องนอน ลองหยิบของ 1 อย่างแล้วบอกเค้กว่า 'อันนี้ของฉัน' หรือ 'อันนี้ของ...' ค่ะ
gìt-jà-gam tîi săam: kŏng nai hông-nawn lawng yìp kŏng nʉ̀ng yàang láew bòk kêk wâa an-níi kŏng chăn rĕu an-níi kŏng...
Activity 3: Things in the bedroom. Pick up one thing and tell me 'This is mine' or 'This is...'s'.
Examples
ตัวอย่าง (dtua-yàang) Example:
(หยิบมือถือ) -> อันนี้มือถือของฉัน
(หยิบหนังสือ) -> อันนี้หนังสือของเพื่อน
เค้กจะถาม: อันนั้นอะไรคะ -> What is that?
แล้วก็ถามว่า: อันนั้นของใครคะ -> Whose is that?
Example:
(Picks up phone) -> This is my phone.
(Picks up a book) -> This is my friend's book.
I will ask: What is that?
And then I'll ask: Whose is that?
