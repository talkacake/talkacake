Script Line 1: บอดี้การ์ด: มีไรครับ

Script Line 1: Bodyguard: What's up?
Examples
คำว่า 'มีไร' เป็นภาษาพูด มาจากคำว่า 'มีอะไร' ค่ะ ใช้ถามเพื่อนได้ว่า 'มีอะไรหรือเปล่า' / 'เป็นอะไรหรือเปล่า' ค่ะ
'ครับ' เป็นคำลงท้ายสำหรับผู้ชายค่ะ
คำศัพท์ใหม่ (New Vocab):
มีอะไร (mii a-rai) = What is it? / What's up?
kam wâa 'mii rai' bpen paa-săa pôot maa jàak kam wâa 'mii a-rai' kâ chái tăam pʉ̂an dâi wâa 'mii a-rai rĕu bplàao' / 'bpen a-rai rĕu bplàao' kâ
'kráp' bpen kam long-táai sǎm-ràp pôo chaai kâ
kam sàp mài:
mii a-rai = What is it? / What's up?
The phrase 'mii rai' is spoken language, from the full phrase 'mii a-rai'. You can use it to ask a friend 'What's wrong?' / 'Is something the matter?'.
'krap' is the polite particle for male speakers.
