🎙️ อัดเสียง · Voice Recorder

อัดเสียง ตัดต่อ และบันทึกเป็นไฟล์ MP3 ลงโฟลเดอร์ใน Google Drive ของคุณเองได้ทันที ทุกคนอัดเสียงและดาวน์โหลดได้ ถ้าจะบันทึกลง Drive ให้เชื่อมต่อบัญชี Google ของคุณเองครั้งเดียวในการตั้งค่า การตั้งค่าเก็บไว้ในเครื่องนี้เท่านั้น ไฟล์เสียงจึงไปที่ Drive ที่คุณเชื่อมต่อไว้เท่านั้นRecord, trim and save MP3s straight into a folder in your own Google Drive. Anyone can record and download here; to save to Drive, connect your own Google account once in Settings. Settings stay on your device, so recordings only ever go to the Drive you connected.

วิธีตั้งค่า (ทำครั้งเดียว) · How to set up (once)
  1. ลงชื่อเข้าใช้บัญชี Google เปิด script.google.com แล้วกด New project (โปรเจกต์ใหม่) ตั้งชื่อว่า “Talk a Cake recorder”Sign in to your Google account, open script.google.com and click New project. Name it “Talk a Cake recorder”.
  2. ลบโค้ดเดิมที่มีอยู่ แล้ววางโค้ดนี้แทน: (ดูโค้ด · view it)Delete the code that's there and paste in this code.
  3. ในบรรทัดแรก ๆ ให้วาง ID ของโฟลเดอร์ใน Drive ที่จะเก็บไฟล์เสียง: เปิดโฟลเดอร์ใน Drive แล้วคัดลอกส่วนของที่อยู่หลัง /folders/ จากนั้นตั้งรหัสผ่านIn the first lines, paste the ID of the Drive folder for your recordings: open the folder in Drive and copy the part of the address after /folders/. Then choose a password.
  4. กด Deploy → New deployment เลือกประเภท Web app ตั้ง Execute as: Me และ Who has access: Anyone แล้วกด Deploy และอนุญาตการเข้าถึงClick Deploy → New deployment, pick type Web app, set Execute as: Me and Who has access: Anyone, then Deploy and allow access.
  5. คัดลอก Web app URL (ลงท้ายด้วย /exec) วางด้านบนพร้อมรหัสผ่านเดียวกัน กด บันทึกการตั้งค่า แล้วกด ทดสอบการเชื่อมต่อCopy the Web app URL (it ends in /exec), paste it above with the same password, press Save settings, then Test connection.

“Anyone” แค่หมายความว่าหน้านี้ติดต่อสคริปต์ได้โดยไม่ต้องลงชื่อเข้าใช้ Google ส่วนสคริปต์จะไม่รับอะไรเลยถ้าไม่มีรหัสผ่านของคุณ“Anyone” only means the page can reach the script without a Google sign-in; the script refuses anything without your password.
