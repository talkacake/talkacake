How to set up (once)
  1. Open script.google.com and click New project. Name it “Talk a Cake recorder”.
  2. Delete the code that's there and paste in this code: (view it)
  3. In the first lines, paste your mp3 folder's ID: open the folder in Drive and copy the part of the address after /folders/. Then choose a password.
  4. Click Deploy → New deployment, pick type Web app, set Execute as: Me and Who has access: Anyone, then Deploy and allow access.
  5. Copy the Web app URL (it ends in /exec), paste it above with the same password, press Save settings, then Test connection.

“Anyone” only means the page can reach the script without a Google sign-in; the script refuses anything without your password.
